## 📝 **File Naming Convention**

All generated PDFs follow a consistent naming pattern:

| Report Type | Filename Pattern |
|-------------|------------------|
| Work Done | `work_done_report_{type}_{date}.pdf` |
| Analyst Performance | `analyst_performance_{date}.pdf` |
| Sample Report | `Sample_Report_{sampleNumber}_{date}.pdf` |
| Deviation Report | `Deviation_Report_{timestamp}.pdf` |
| CAPA Report | `CAPA_Report_{timestamp}.pdf` |

**Timestamp Format**: `yyyyMMdd_HHmmss` or `yyyyMMdd-HHmmss`

## 🚀 **How to Use**

### For End Users:

1. **Navigate to Reports Page**:
   - Click "Reports & Certificates" in the sidebar
   - Choose the report type you need
   - Configure filters/options (if available)
   - Click the "Generate PDF" button
   - PDF will automatically download

2. **From Deviations Page**:
   - Navigate to "Deviations & CAPA"
   - Apply any filters you want
   - Click "Generate Report" button
   - PDF will include filtered results

3. **Individual Sample Reports**:
   - Go to Reports page
   - Select "Certificate of Analysis"
   - Choose an approved sample
   - Click "Generate COA"

### For Developers:

```typescript
import ReportGenerator from '../utils/reportGenerator';

// Create a new report generator instance
const generator = new ReportGenerator();

// Generate a custom report
generator.generateDeviationSummaryReport(
  deviations,
  'John Doe',
  { status: 'open', severity: 'critical' }
);

// Save the PDF
generator.save('my_custom_report.pdf');

// Or get as blob for upload
const blob = generator.getBlob();
```
