# PDF Report Generation - User Guide

## 🎯 Quick Start: Where to Find PDF Reports

Your Pharma QC application has **PDF report generation available in 2 main locations**:

---

## 📍 **Location 1: Reports & Certificates Page**

**How to Access**: Click **"Reports & Certificates"** in the sidebar menu

### Available Reports:

#### 1️⃣ **Work Done Report**
**What it does**: Shows all samples processed in a specific time period

**Steps**:
1. Select report type: Daily, Weekly, or Monthly
2. Choose a date
3. Click **"Generate PDF"** button
4. PDF downloads automatically

**Report includes**:
- Total samples processed
- Completed vs In Progress counts
- Sample details (ID, Product, Batch, Status)
- Analyst assignments
- Test completion ratios

---

#### 2️⃣ **Analyst Performance Report**
**What it does**: Shows performance metrics for all analysts

**Steps**:
1. Click **"Generate Performance Report"** button
2. PDF downloads automatically

**Report includes**:
- Workload per analyst
- Completion rates
- Average turnaround times
- Performance statistics

---

#### 3️⃣ **Certificate of Analysis (COA)**
**What it does**: Official test certificate for approved samples

**Steps**:
1. Select an approved sample from dropdown
2. Click **"Generate COA"** button
3. PDF downloads automatically

**Report includes**:
- Sample identification
- Product and batch details
- All test results
- Specifications and compliance
- Official certificate format

---

#### 4️⃣ **Deviation Summary Report**
**What it does**: Comprehensive summary of all deviations

**Steps**:
1. Click **"Generate Deviation Report"** button
2. PDF downloads automatically

**Report includes**:
- Total deviations count
- Statistics by severity (Critical, Major, Minor)
- Statistics by status (Open, Under Investigation, Closed)
- Detailed deviation list
- Investigation details

---

#### 5️⃣ **CAPA Effectiveness Report**
**What it does**: Analysis of Corrective and Preventive Actions

**Steps**:
1. Click **"Generate CAPA Report"** button
2. PDF downloads automatically

**Report includes**:
- Total CAPAs count
- Corrective vs Preventive breakdown
- Effectiveness statistics
- Detailed CAPA list
- Verification status

---

## 📍 **Location 2: Deviations & CAPA Page**

**How to Access**: Click **"Deviations & CAPA"** in the sidebar menu

### Smart Report Button:

**Location**: Top-right corner, next to "New Deviation" / "New CAPA" button

**How it works**:
- When viewing **Deviations tab**: Generates Deviation Report
- When viewing **CAPAs tab**: Generates CAPA Report
- **Respects your filters**: Only includes filtered results!

**Steps**:
1. (Optional) Apply filters:
   - Search by deviation number or title
   - Filter by status (Open, Under Investigation, etc.)
   - Filter by severity (Critical, Major, Minor)
2. Click **"Generate Report"** button
3. PDF downloads with filtered data

**Pro Tip**: Use filters to create focused reports (e.g., only Critical deviations, only Open CAPAs)

---

## 📥 **Where Do PDFs Download?**

PDFs automatically download to your browser's default download folder.

**Filename Examples**:
- `work_done_report_daily_2025-11-25.pdf`
- `analyst_performance_2025-11-25.pdf`
- `Sample_Report_S-2025-001_20251125.pdf`
- `Deviation_Report_20251125_142530.pdf`
- `CAPA_Report_20251125_142530.pdf`

## 💡 **Tips & Best Practices**

### 1. **Use Filters for Focused Reports**
Before generating a Deviation or CAPA report from the Deviations page:
- Apply filters to get only what you need
- Search for specific items
- Filter by date, status, or severity

### 2. **Choose the Right Report Type**
- **Daily Report**: For end-of-day summaries
- **Weekly Report**: For weekly meetings
- **Monthly Report**: For monthly reviews and management

### 3. **COA for Approved Samples Only**
The Certificate of Analysis dropdown only shows approved samples. If you don't see a sample, check its approval status first.

### 4. **Performance Reports for Reviews**
Generate Analyst Performance reports before:
- Performance reviews
- Resource planning
- Workload balancing decisions

### 5. **Regular Deviation Reports**
Generate monthly deviation reports to:
- Track trends
- Identify recurring issues
- Support quality meetings

## 🔍 **Troubleshooting**

### ❌ **PDF Not Downloading**
**Solutions**:
1. Check browser's download settings
2. Allow pop-ups for this site
3. Check browser console for errors (F12)
4. Try a different browser

### ❌ **Empty Report / No Data**
**Causes**:
- No data exists for selected filters
- Date range has no samples
- All deviations filtered out

**Solutions**:
- Remove filters and try again
- Select a different date range
- Verify data exists in the system

### ❌ **Report Button Not Visible**
**Solutions**:
1. Check your user role/permissions
2. Refresh the page
3. Ensure you're on the correct page

## 📊 **Report Content Reference**

### Work Done Report Contains:
| Column | Description |
|--------|-------------|
| Sample ID | Unique sample identifier |
| Product | Product name |
| Batch | Batch number |
| Received | Date sample was received |
| Status | Current sample status |
| Analyst | Assigned analyst name |
| Tests | Completed tests / Total tests |

### Analyst Performance Report Contains:
| Column | Description |
|--------|-------------|
| Analyst | Analyst name |
| Assigned | Total samples assigned |
| Completed | Samples completed |
| Completion % | Completion percentage |
| Avg. Turnaround | Average days to complete |

### Deviation Report Contains:
| Column | Description |
|--------|-------------|
| Number | Deviation number |
| Title | Deviation title |
| Severity | Critical / Major / Minor |
| Status | Current status |
| Reported | Date reported |
| Investigator | Assigned investigator |

### CAPA Report Contains:
| Column | Description |
|--------|-------------|
| Number | CAPA number |
| Title | CAPA title |
| Type | Corrective / Preventive |
| Status | Current status |
| Target Date | Target completion date |
| Effectiveness | Effective / Not Effective / Pending |
